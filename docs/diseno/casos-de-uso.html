Especificación

Flujo principal, flujos alternos y condiciones de cada caso de uso.

CU-01

Iniciar sesión

RF-01P3
Actor
Recepcionista, Administrador
Precondición
El usuario existe y está activo.
Flujo principal
  1. El usuario abre el sistema.
  2. Ingresa usuario y contraseña.
  3. El sistema valida las credenciales.
  4. Muestra el menú según el rol.
Flujos alternos
  • 3a. Credenciales inválidas → «Usuario o contraseña inválidos».
  • 3b. Usuario inactivo → «Usuario deshabilitado, contacte al administrador».
Postcondición
Sesión activa con su rol.
CU-02

Registrar servicio

RF-02P5P5a
Actor
Administrador
Precondición
Sesión iniciada como administrador.
Flujo principal
  1. Entra a Servicios.
  2. Pulsa Nuevo servicio.
  3. Ingresa nombre, prefijo y descripción.
  4. Pulsa Guardar.
  5. El sistema valida y lo muestra en la lista.
Flujos alternos
  • 5a. Prefijo duplicado → pide otro.
  • 5b. Campos obligatorios vacíos → los marca en rojo.
  • 1a. Editar o desactivar: elige un servicio, cambia datos o estado y guarda (RN-04).
Postcondición
El servicio aparece (o deja de aparecer) en el kiosco.
CU-03

Generar turno

RF-03P1P1b
Actor
Cliente
Precondición
Existe al menos un servicio activo.
Flujo principal
  1. El cliente toca un servicio en el kiosco.
  2. El sistema calcula el siguiente número del día para ese servicio (RN-01).
  3. Crea el turno en estado EN_ESPERA.
  4. Muestra el código (C-015) y las personas delante.
Flujos alternos
  • 2a. Error de conexión → «Intente de nuevo»; no se crea el turno.
Postcondición
Turno EN_ESPERA en la cola del servicio.
CU-04

Ver turno actual

RF-04P2
Actor
Cliente
Precondición
Pantalla pública encendida.
Flujo principal
  1. La pantalla consulta los turnos llamados cada 3 segundos.
  2. Muestra en grande el último turno y su ventanilla.
  3. Lista los 5 anteriores.
  4. Si hay un llamado nuevo, lo resalta y emite un tono.
Flujos alternos
  • 1a. Sin turnos llamados hoy → «Bienvenido, en breve le atenderemos».
Postcondición
Ninguna (solo lectura).
CU-05

Llamar siguiente turno

RF-05P4b
Actor
Recepcionista
Precondición
Sesión iniciada, ventanilla asignada y sin turno abierto (RN-03).
Flujo principal
  1. Pulsa Llamar siguiente.
  2. El sistema busca el turno EN_ESPERA más antiguo de los servicios de su ventanilla (RN-02).
  3. Lo cambia a LLAMADO con hora, ventanilla y usuario.
  4. El turno aparece en la pantalla pública.
Flujos alternos
  • 2a. No hay turnos en espera → «No hay clientes en espera».
  • 1a. Tiene un turno abierto → el botón está deshabilitado.
Postcondición
Turno en estado LLAMADO.
CU-06

Marcar atendido

RF-06P4
Actor
Recepcionista
Precondición
Tiene un turno LLAMADO.
Flujo principal
  1. Termina la atención.
  2. Pulsa Atendido.
  3. El sistema guarda la hora de fin y el estado ATENDIDO.
Flujos alternos
  • 2a. El cliente no llegó → No se presentó → NO_PRESENTADO.
  • 2b. Volver a llamar → el turno se anuncia otra vez en pantalla.
Postcondición
Ventanilla libre para llamar otro turno.
CU-07

Consultar turnos

RF-07P6
Actor
Administrador, Recepcionista
Precondición
Sesión iniciada.
Flujo principal
  1. Entra a Consultar turnos.
  2. Filtra por fecha, servicio y estado.
  3. El sistema muestra la tabla y los totales: atendidos, no presentados y espera promedio.
Flujos alternos
  • 3a. Sin resultados → «Sin turnos para ese filtro».
Postcondición
Ninguna (solo lectura).
CU-08

Gestionar usuarios y ventanillas

RF-08P5bP5cP5d
Actor
Administrador
Precondición
Sesión iniciada como administrador.
Flujo principal
  1. Crea una ventanilla y marca los servicios que atiende.
  2. Crea un usuario recepcionista con nombre, usuario y contraseña.
  3. Lo asigna a la ventanilla.
  4. Guarda.
Flujos alternos
  • 2a. Usuario duplicado → pide otro.
  • 3a. Desactivar usuario → ya no puede iniciar sesión.
Postcondición
El recepcionista puede atender en esa ventanilla.
